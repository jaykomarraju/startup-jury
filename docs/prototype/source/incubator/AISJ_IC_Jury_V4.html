My Parameters — Role configuration
Define up to 3 custom evaluation parameters per role
Role configurable parameters
Each role can add up to 3 custom evaluation parameters on top of the 13 standard areas. These parameters are personal to that role's evaluation lens and appear in their scoring view and in reports attributed to them. Pro plan required per user to activate.
How this works: Each role defines their 3 parameters with a label, a description visible to them during scoring, and an AI extraction prompt. The AI pre-populates a suggested score for their custom parameters just as it does for the 13 standard areas. The user can override. These scores feed into role-specific reports but are clearly labelled as custom parameters.
Permission to configure additional parameters
Super Users and Client Admins can edit by default. Other roles are read-only here unless granted the “Configure 3 additional parameters” permission in Admin → Team & roles.
Previewing as

Customise AI extraction prompts for each of the 13 evaluation areas
AI prompt customisation
Customise the AI engine's prompt for each of the 13 evaluation areas. The system prompt tells the AI how to read the pitchdeck for that area, classify signal strength, generate a score, and decide whether to trigger clarification questions to the founder.
How this works: For each area, the AI prompt has three parts — (1) an extraction prompt that tells the AI what to look for in the deck, (2) signal classification instructions defining what Strong / Moderate / Weak / Absent looks like, and (3) clarification trigger instructions that define when to send questions to the founder.
