# ai.STARTUPJURY — buildable specification extracted from the prototypes

Generated 2026-09-09 alongside the Prototype Parity Audit. Every line below is a requirement read
directly out of a prototype panel, the embedded Admin console (`var ADMIN_B64` → `openAdmin()`), or
one of the two written product specs at `/specs/incubator` and `/specs/vc` on the prototype portal.

This is the implementation contract for the areas the audit found unbuilt. It is deliberately literal —
where the prototype and the written spec disagree, the written spec wins and the line says so.

⚠️ Three items must NOT be built as drawn — see §7 of the report: the User access password reveal,
in-app card capture in the seat/purchase flows, and the "Mentor can adjust composite" toggle.
